## Description

**deboa-tls** tls extension crate for deboa http client.

## Install

Either run from command line:

`cargo add deboa deboa-tokio deboa-tls`

Or add to your `Cargo.toml`:

```toml
deboa = { version = "0.1.4" }
deboa-tokio = { version = "0.1.1" }
deboa-tls = { version = "0.1.1" } 
```

## Crate features

- rust-tls (default)
- native-tls
